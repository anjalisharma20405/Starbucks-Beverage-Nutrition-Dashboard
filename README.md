# Starbucks Beverage Nutrition Dashboard ☕

## Project Overview
This project is an interactive Starbucks Beverage Nutrition Dashboard created using Power BI. It provides insights into the nutritional information of different Starbucks beverages.

## Key Performance Indicators (KPIs)
- Total Beverage
- Average Sugar
- Average Calories
- Average Caffeine

## Dashboard Features
- Average Calories by Beverage Category
- Starbucks Global Presence
- Beverage Category Distribution
- Average Caffeine by Category
- Top 5 Highest Caffeine Beverages
- Protein Range Filter
- Beverage Preparation Filter

## Tools Used
- Microsoft Power BI
- Data Analysis
- Data Visualization

## Project Objective
The objective of this project is to analyze Starbucks beverage nutrition data and present important insights through interactive charts, filters, and KPIs.
